Sermon Analyzer

SISA — a free Windows program for studying how a sermon handles Scripture

SISA — the Super Intelligent Sermon Analyzer, which reads a sermon transcript and returns a report on the Scripture used at each timestamp, any specific application callouts, transition words, potential technical terms, and a catalogue of contestable verses used with other interpretations explained.

Simply input the YouTube link and it should pull the transcript, title, and date. You can download the report as a PDF
