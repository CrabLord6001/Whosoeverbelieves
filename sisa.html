Sermon Analyzer

SISA — a free Windows program for studying how a sermon handles Scripture

Nothing in it is intelligent. It counts, matches and measures, the same way twice, which is the point. Give it a sermon transcript and it returns a report: where Scripture was used, what was quoted without a reference, whether the passage named was the passage read, what the hearer was actually asked to do, and which terms went unexplained.

Everything runs on your own machine. No API key, no account, no network connection.

What it reports

  • Scripture use. Every reference named aloud, every passage quoted without one, and whether the text read matches the text cited.
  • Contested passages. Where the sermon touches a disputed text, which reading it took, and whether that reading agrees or conflicts with Free Grace theology.
  • Structure. How the time was divided between exposition, illustration and application.
  • Instructions. What the hearer was actually told to do, pulled out and listed.
  • Vocabulary. Theological terms used without explanation.
  • Original languages. Claims made about Greek and Hebrew words, checked against the text.

Running it

  • Unzip the whole folder. The executable on its own will not run.
  • Double-click SISA.exe. A console window opens and the page opens in your browser. Leave that window alone while you work — closing it stops the program.
  • Paste a transcript, or give it a YouTube link and it fills in the title, preacher, church and date and fetches the captions for you.

It is not code-signed, so the first time you run it Windows says “Windows protected your PC.” Choose More info, then Run anyway. A signing certificate costs a few hundred dollars a year, which is worth it only once strangers are installing it.

A note on what it is for

A report is not a verdict. The program measures what a sermon did with the text; it does not know whether the sermon was faithful, or clear, or edifying. Those judgments belong to the hearer. What it offers is a consistent second look — the same questions asked of every sermon, including your own.
