Memory Rooms

“I have hidden your word in my heart, that I might not sin against you.”Psalm 119:11 — WEB

Struggling to memorize Scripture or don't know how to start? This tool walks you through an exercise in associating each segment of a verse with an object in a classical painting and crafting a memory or elaborate story for each in a sequence. Then you practice by repeating the story as you journey mentally through the room of objects. New to memory rooms? Start with The Power to Memorize Scripture.

Next, break the verse into short phrases. We've suggested the breaks — tap any word to add or remove one.

Now choose a room and give each phrase a home. Click an object on the painting for the highlighted phrase, in any order you like.

Then connect each phrase to its object with a line of story. The stranger and more personal, the better it sticks.

Finally, practice in three stages: walk the room with your story, strengthen it with the drills, then recite the whole verse from memory.
